Hướng Dẫn Đóng Gói & Cài Đặt App

Cài đặt làm App trên Android, iPhone, Windows & macOS

Cách 1: Cài đặt trực tiếp (PWA - Khuyên dùng)

Phần mềm này đã hỗ trợ chuẩn PWA (Progressive Web App). Bạn không cần đóng gói phức tạp mà vẫn cài đặt được như App gốc, chạy mượt mà không cần mạng Internet.

Điện thoại Android & Chrome
  1. Bấm nút "Cài Đặt App" góc trên màn hình.
  2. Hoặc bấm nút ⋮ (3 chấm) ở góc trình duyệt -> Chọn "Thêm vào MH chính" hoặc "Cài đặt ứng dụng".
iPhone / iPad (Safari)
  1. Mở web bằng trình duyệt Safari.
  2. Bấm nút Chia sẻ (Icon hình vuông có mũi tên lên).
  3. Cuộn xuống chọn "Thêm vào Màn hình chính" (Add to Home Screen).

Cách 2: Đóng gói thành file cài đặt APK / EXE

Nếu bạn muốn xuất thành file .APK (Android) hoặc .EXE (Windows) để gửi cho người khác cài đặt:

1. Dùng PWABuilder (Miễn phí từ Microsoft)

Truy cập https://www.pwabuilder.com, dán đường dẫn web của bạn vào. Hệ thống sẽ tự động tạo gói file `.apk` cho Android và `.msix/.exe` cho Windows chỉ sau 1 cú nhấp chuột.

2. Dùng WebIntoApp / Web2App

Truy cập https://www.webintoapp.com, tải file `index.html` lên -> Nhập tên "Café POS" -> Bấm "Generate APK" để tải file APK về điện thoại.

3. Cho Lập Trình Viên (Capacitor / Electron / Tauri)

Tạo dự án Capacitor: npm init @capacitor/app -> Đưa file `index.html` vào thư mục `www` -> Chạy lệnh build Native cho iOS/Android.
